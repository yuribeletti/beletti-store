# Beletti Store

Loja dos apps Beletti: instala e atualiza todos os apps direto das releases deste repositório.
Gratuita, sem anúncios e sem coleta de dados.

- `catalogo.json`: lista de apps que a loja mostra
- `icones/`: ícones usados no catálogo
- `loja/`: código-fonte do Beletti Store (Android)
- **Releases**: os APKs de cada app (tags `store-v1.0`, `techsuite-v4.5`, …)

Criado por Yuri Beletti e Claude (Anthropic).
